# 🛡️ IPARK리조트 안전사고 모니터링 시스템 (IPARK Resort Incident Hub)

리조트(오크밸리, 파크로쉬, 밸리CC, 성문안팀, 아이파크 콘도 등)에서 발생하는 각종 안전사고를 **건별 및 유형별·팀(부서)별·구역별**로 한눈에 모니터링하고, **KPI 카드별 고유 전용 심층 분석 모달 5종**, **실무 엑셀(약 500건+) 대량 불러오기 자동 매핑**, **차트 드릴다운 필터링**, **순번(No.) 및 페이지당 보기**, **기존 데이터 수정(Edit)·삭제**를 통합 지원하는 웹 기반 안전 관리 플랫폼입니다.

---

## 📌 주요 기능 및 최신 개선 사항

### 🎯 테이블 상단 간이 필터 바 & 차트 클릭 스크롤 점프 버그 수정 (신규 ⭐)
- **테이블 상단 전용 간이 빠른 필터 툴바 탑재**:
  - 도넛 차트의 미세한 조각을 일일이 클릭하지 않고도 메인 테이블 바로 위에서 즉시 원하는 조건 선택 가능
  - ① `[사고유형 빠른 필터]`: 데이터 내 존재하는 전체 사고유형(넘어짐, 타구사고, 카트사고, 차량사고, 부딪힘 등) 나열
  - ② `[구역/장소 빠른 필터]`: 골프 코스, 객실, 사우나/스파, 레저/부대시설, 주차장/도로 등 전체 구역 나열
  - ③ `[피해구분 빠른 필터]`: 경미(현장처치), 중등(병원진료), 중대(입원/후송), 단순 대물 등
  - ④ `[필터 해제]` 버튼: 간이 필터를 한 번에 기본값으로 초기화
- **실시간 조건 뱃지(Chips) 및 개별 ✕ 해제 지원**:
  - 활성화된 필터 조건들이 테이블 상단에 태그 뱃지(예: `유형: 넘어짐 ✕`, `구역: 골프 코스 ✕`)로 즉시 시각화
  - 개별 뱃지의 `✕` 클릭 시 해당 조건만 핀포인트로 해제 가능
  - 상단 메인 필터 및 차트 드릴다운과 **양방향 완벽 동기화** 연동
- **도넛/막대 차트 클릭 시 강제 스크롤 점프 완전 제거**:
  - 기존에 차트 조각 클릭 시 테이블 영역으로 화면이 툭 떨어지던 `scrollIntoView()` 강제 스크롤 이동 제거
  - 차트를 클릭하더라도 현재 보고 있는 스크롤 위치를 편안하게 유지한 채, 하단 테이블 데이터와 차트 강조 스타일만 조용히 갱신

### 0. 💾 558건 실무 데이터 영구 보존 및 LocalStorage 저장 구조 고도화 (신규 ⭐)
- **실무 엑셀 원본 558건 전체를 기본 데이터셋(`data.js`)으로 고정 영구 탑재**:
  - `INITIAL_INCIDENTS` 및 `window.initialIncidents` 변수에 실무 엑셀(2023년~2026년 10월) 558건을 100% 완전 파싱하여 영구 내장
  - 브라우저 캐시나 로컬스토리지가 완전히 비워진 새 브라우저에서도 기본 실행 시 558건의 실무 데이터가 항상 즉시 로드
- **로컬스토리지(`resort_incidents_data`) 1순위 로드 및 새로고침 영구 보존**:
  - 페이지 로드 시 반드시 `localStorage.getItem('resort_incidents_data')`의 존재를 1순위로 확인
  - 저장된 데이터가 1건이라도 존재하면 샘플 데이터로 덮어쓰지 않고 로컬스토리지 데이터를 그대로 유지하여 화면에 로드
  - 엑셀 업로드 완료 시 전체 데이터(558건+)를 즉시 `localStorage`에 영구 보존 저장
  - 오직 사용자가 상단 우측의 **[샘플 초기화]** 버튼을 직접 클릭하고 확인 팝업을 승인했을 때만 초기화되도록 분기 완벽 분리

### 1. 📋 테이블 순번(No.) 열 추가 및 페이지당 표시 건수(Rows Per Page) 옵션 (신규 ⭐)
- **전체 데이터 기준 누적 순번(No.) 컬럼 탑재**:
  - 메인 사고 목록 테이블 첫 번째 열에 `No.` 컬럼 배치 (중앙 정렬, 60px 콤팩트 너비)
  - 페이징 시 전체 데이터 기준의 연속 누적 번호 표시 `((현재페이지 - 1) * 페이지당건수 + index + 1)`
- **페이지당 표시 건수(Rows Per Page) 선택 드롭다운 (`#pageSizeSelect`)**:
  - 테이블 하단 좌측 건수 표기 옆에 위치
  - 옵션: `[10개씩 보기 (기본)]`, `[50개씩 보기]`, `[100개씩 보기]`, `[300개씩 보기]`, `[500개씩 보기]`
  - 건수 변경 시 즉시 1페이지로 자동 리셋되며, 선택한 건수만큼 한 번에 렌더링되고 하단 페이지네이션 버튼도 실시간 재계산

### 2. 🏢 팀(부서)별 사고 비중 원형(도넛) 차트 & 상단 다중 필터 확장 (신규 ⭐)
- **'🏢 팀/부서별 사고 발생 비중' 도넛 차트 신설**:
  - 기존 2개 차트 레이아웃을 3개 차트 레이아웃으로 확장 (`유형별 비중` + `팀/부서별 비중` + `구역별 건수`)
  - 엑셀 및 로컬 데이터의 팀/부서(밸리팀, 성문안팀, 레저팀, 시설팀, 객실팀, 안전관리팀, 식음팀, 경기운영팀 등)별 발생 건수 자동 집계
  - **차트 범례(Legend) 및 툴팁에 팀명과 함께 '실제 발생 건수'와 '비율(%)'을 명확한 수치로 동시 표기** (예: `밸리팀 (12건, 24.0%)`)
  - 특정 팀 조각 클릭 시 하단 목록이 해당 팀 데이터로 원클릭 필터링(드릴다운) 연동
- **상단 상세 필터 바(Filter Bar) 5종 콤보박스 확장**:
  - `[사업장/구역]`: 전체 사업장 및 구역 필터
  - `[팀/부서]`: 데이터 내 존재하는 팀 목록 자동 추출 및 필터링
  - `[사고 유형]`: 넘어짐, 타구사고, 카트사고, 감전 등
  - `[피해 구분]`: 경미(현장처치), 중등(병원진료), 중대(입원/후송), 단순 대물 등
  - `[처리 상태]`: 조치완료, 조사/진행중, 보험/보상진행, 접수대기 등
  - `[기간 선택 태그]`: 전체, 최근 7일, 최근 30일, 최근 3개월, 2026년
  - `[필터 초기화] 버튼`: 클릭 한 번으로 모든 검색어와 다중 필터 조건을 디폴트로 즉시 리셋 (AND 조건 연동)

### 4. 🎯 KPI 카드별 전용 심층 분석 모달 (5종 전체 완비)
각 KPI 카드에 마우스 오버 시 입체 호버 애니메이션 및 `🔍 상세 분석` 뱃지가 표시되며, 클릭 시 고유 특성에 맞춘 전용 모달이 팝업됩니다:

1. **[총 사고 발생 건수] 카드** → **`📊 사고 발생 추이 및 통계 브리핑` 모달**
   - 연도별(2023~2026) 연간 발생 건수 비교 미니 바 차트
   - 최다 발생 사업장 TOP 3 & 사고유형 TOP 3 카드
   - 사업장 선택 드롭다운: 특정 사업장 선택 시 해당 사업장의 1월~12월 월별 발생 패턴 차트 동적 렌더링
2. **[조사 및 조치 진행 중] 카드** → **`⏳ 미완료/진행 중 사고 집중 관리` 모달**
   - 미결 건 전용 필터링 테이블 (상태: '진행중' 또는 '조사중')
   - 경과일 경고 뱃지: 발생일로부터 경과 일수(`🚨 D+7일 이상`, `⚠️ D+3~6일`, `ℹ️ D+1~2일`) 시각적 표기
   - 인라인 [⚡ 완료 처리] 빠른 버튼: 테이블 행에서 즉시 조치 내용을 입력하고 '조치완료'로 원클릭 상태 전환
3. **[사고 조치 완료율] 카드** → **`🛡️ 재발 방지 및 시설 개선 대책 모음` 모달**
   - 재발 방지 및 시설 개선 카드 그리드
   - 사업장 및 부서별(시설팀, 조경팀, 안전관리팀 등) 필터 콤보박스
   - 카드 클릭 시 상세 모달 원활 연결
4. **[병원 진료 / 보상 건] 카드** → **`🏥 인명 피해 및 의료 후송 현황 분석` 모달**
   - 피해자 구분(고객 vs 직원 vs 캐디/협력사) 비율 도넛 차트
   - 피해 심각도 4단계 요약 카드: 경미(현장처치), 중등(병원진료), 중대(입원/후송), 단순대물
   - 병원 치료 내역 상세 테이블: 치료 내역 및 병원비 발생 건 모아보기 및 상세 보기 연결
5. **[당사 지급 / 보상 비용] 카드** → **`💳 당사 지급 보상·보험 비용 조회` 모달**
   - 연도 드롭다운 콤보박스 & 직접 기간 지정(From~To)
   - 지급 총액 / 지급 건수 / 평균 지급액 하이라이트 배너
   - 유효 지급 건별 상세 목록 테이블 및 상세 모달 연결

### 5. ⚡ 차트 원클릭 드릴다운(Drill-down) 필터링
- **'유형별 사고 발생 비중' 도넛 차트**: 조각 클릭 시 해당 사고유형으로 하단 목록 자동 필터링
- **'팀/부서별 사고 발생 비중' 도넛 차트**: 조각 클릭 시 해당 팀 데이터로 하단 목록 자동 필터링
- **'주요 구역/시설별 사고 건수' 막대 차트**: 바 클릭 시 해당 구역 데이터로 자동 필터링
- **실시간 활성 드릴다운 뱃지 및 원클릭 리셋**:
  - 메인 테이블 상단에 `[필터링 중: 부서 - 밸리팀 ✕]` 활성 태그 표시, 클릭 시 해제
  - 차트 배경 빈 공간 클릭 시에도 드릴다운 필터 자동 해제

### 6. 실무 엑셀 파일(500건+) 대량 불러오기 & 열 자동 매핑
- **우측 상단 [📥 엑셀 불러오기] 버튼**: 클릭 시 `.xlsx, .xls` 파일을 바로 선택하여 브라우저에서 직접 초고속 파싱 (SheetJS 탑재)
- **실무 엑셀 열(Header) 1:1 자동 매핑 규격**:
  - `문서번호` → `docNo`
  - `부문/부서` → `dept` (밸리팀, 시설팀, 레저팀, 객실팀 등)
  - `구분1` → `area` / `사업장`
  - `위치(세부)` → `locationDetail`
  - `구분2` → `victimType`
  - `기안일` → `reportDate`
  - `발생일시` → `occurDate`
  - `사고유형` → `incidentType`
  - `내용` → `description`
  - `제목` → 엑셀에 별도 제목 열이 없더라도 `[위치] 사고유형` 형태로 자동 생성
  - `보험/보상금액` → 엑셀에 없을 경우 기본 0원 및 '과실 미산정'으로 스마트 초기화
- **업로드 완료 후 선택 팝업**: [확인](기존 데이터와 병합) / [취소](새 엑셀 데이터로 완전 대체)
